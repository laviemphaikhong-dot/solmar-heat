Solmar Heat is a 2D top-down open-world crime game set in the fictional city of Solmar Bay. Explore a 7x7-block city on foot or steal and drive any car, weave through AI traffic and pedestrians, run a three-job courier story for Marisol and then endless paid deliveries, and escape a 0-5 star wanted system with police cruisers that pursue, ram and bust you. Pure HTML/CSS/JavaScript on a canvas - no assets, no build step - with a live HUD and minimap, synthesised WebAudio sound, and localStorage saves.

## Run it

```sh
node serve.ts --port 8123
```

Then open http://localhost:8123 in a browser. WASD or arrow keys to move and drive, E or F to enter and exit cars, Shift to sprint, Space to shove, M to mute, N for a new game.
